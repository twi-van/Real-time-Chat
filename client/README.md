# client — Frontend

**Phụ trách:** Kim Lợi  

Stack định hướng: React + Vite + JavaScript + Tailwind.

```text
src/
├── pages/        # Login, Register, Chat
├── components/   # Chat layout, Message, Sidebar
├── hooks/        # useSocket, …
└── stores/       # state (vd. Zustand)
```

Tuần 1: điền `docs/ui-outline.md` rồi scaffold:

```bash
npm create vite@latest . -- --template react
```
