# server — Backend

**Phụ trách:** Thùy Vân (code) · Diệu Hiền (`prisma/`)

Stack định hướng: Node.js + JavaScript + Socket.io + REST.

```text
src/
├── auth/         # register, login, JWT
├── socket/       # WebSocket events
├── routes/       # REST API
└── middleware/   # auth, rate limit
prisma/           # schema, migrate, seed (Diệu Hiền)
```

Bám `docs/api-contract.md`. Sau sync tuần 1 mới init package + code.
